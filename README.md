# FormAngular

Exemplo didático de formulário Angular baseado em template-driven forms, com validação de e-mail e sugestão de nome.

## Diretório da aplicação

A aplicação está em `form/`. Execute os comandos nessa pasta:

```sh
cd form
npm ci
npm start
```

Build e testes: `npm run build` e `npm test`.

Este exemplo exibe os dados enviados apenas para demonstrar o binding. Não use respostas secretas ou dados pessoais reais. A autenticação e o envio para um servidor não estão implementados.
